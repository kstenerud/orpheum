# Built with AI

Nearly every line of this repository (the Go server, the React clients, the
container builds, the deployment, the gates that check them, and the documentation) was
written by Claude agents, directed and reviewed by an engineer.

Can this be done reliably? [Yes, it can](docs/contributors/how-it-is-built.md).
