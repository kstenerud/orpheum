> **ABOUTME:** Principle §40: What needs the person comes before what does not, is absent when
> nothing is wrong, and every way to it reads the same count.

# §40 — Problems come first

A person opening an admin page is most often there because something is wrong. So a page shows what
needs them first, in its Needs you section, each problem with its fix or the way to it, and shows no
such section when nothing is wrong. An empty "All good" box is noise that teaches the person to skip
the place.

The way to a problem is marked where the person already looks: the main menu's entry for its page,
and the header's warning sign, which leads to the Needs attention page (D538 §12, D280 §4). The
menu, the sign and the pages read the same counts, so they never disagree.

**Bites when:** a problem is reported below the page's ordinary content, an empty Needs you section
is shown, or the sign and a page count a problem differently.
