# §41 — One way for each kind of interaction

[§4](04-one-way.md) for the interface. There is one way to confirm, one dialog, one pop-up, one way
to step a number, and two ways for a form to save, never mixed in one section; each is one shared
part (D538 §1). A person who has used one dialog has used them all, and on a TV, where each step
costs a press, a surprise costs most.

A screen that seems to need a new way asks for a new part, or a change to the existing one, through
the standard's catalogue ([ui.md](../standards/ui.md)); it does not grow one of its own.

**Bites when:** a screen builds its own dialog, confirm, toggle or number control, or one section
saves itself while its neighbour waits for Save.
