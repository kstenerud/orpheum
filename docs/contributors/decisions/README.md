# Decisions

The append-only decision log. Each entry is a proto-ADR — what was decided, what was rejected,
why, and the consequences — with a stable `D`-number that other docs cite.

- **[index.md](index.md)** — one line per decision, and the later entries that revisit it. Start
  here to find a decision or to check whether one still stands.
- **[working-notes.md](working-notes.md)** — the live log: every decision with something in it
  that is still the design. New decisions append to the bottom.
- **[working-notes-archive.md](working-notes-archive.md)** — decisions in which nothing is
  current any more, each with a note naming its successor.
- **[conventions.md](conventions.md)** — how the log is kept: numbering, supersession, archiving,
  citing.
